# Contract: Service Interfaces

C# signatures exposed to Pages and Endpoints (all in `ContosoDashboard.Services`). Interfaces only; implementation details belong in tasks. Every `IDocumentService` method takes the acting `requestingUserId` and enforces authorization itself (Constitution III). Methods that fail authorization return a failed `DocumentOperationResult`, `null`, or an empty list, matching the existing services; they do not throw.

## IFileStorageService (infrastructure abstraction)

```csharp
public interface IFileStorageService
{
    // storagePath is a relative, forward-slash path generated by the caller: {userId}/{projectId|personal}/{guid}.{ext}
    Task<string> UploadAsync(Stream content, string storagePath, string contentType, CancellationToken ct = default);
    Task DeleteAsync(string storagePath, CancellationToken ct = default);          // no error if the file is already gone
    Task<Stream> DownloadAsync(string storagePath, CancellationToken ct = default); // FileNotFoundException if missing
    Task<string> GetUrlAsync(string storagePath, TimeSpan expiration);              // local: returns storagePath (not browsable)
}
```

Contract rules:
- Implementations MUST reject any path that resolves outside the storage root (`ArgumentException`).
- `UploadAsync` MUST NOT overwrite an existing file (fail if the path exists).
- Local implementation: `LocalFileStorageService`, root from `FileStorage:RootPath` (default `AppData/uploads`).
- Registered as scoped or singleton via DI; swapping to Azure Blob changes only registration.

## IMalwareScanService (infrastructure abstraction)

```csharp
public enum MalwareScanStatus { Clean, Infected, Unavailable }

public record MalwareScanResult(MalwareScanStatus Status, string? Reason = null);

public interface IMalwareScanService
{
    Task<MalwareScanResult> ScanAsync(Stream content, string fileName, CancellationToken ct = default);
}
```

Contract rules:
- The stream is rewound to its start by the caller before and after the scan; implementations MUST NOT dispose it.
- Any internal failure or timeout MUST be returned as `Unavailable` (callers treat it as a rejection).
- Local implementation: `LocalSignatureScanService` flags the EICAR test string as `Infected`.

## IDocumentService (business logic)

```csharp
public interface IDocumentService
{
    // Upload and file lifecycle
    Task<DocumentOperationResult> UploadAsync(DocumentUploadRequest request, int requestingUserId);
    Task<DocumentOperationResult> ReplaceFileAsync(int documentId, DocumentUploadRequest file, int requestingUserId);
    Task<DocumentOperationResult> DeleteAsync(int documentId, int requestingUserId);

    // Metadata
    Task<DocumentOperationResult> UpdateMetadataAsync(int documentId, string title, string? description, string category, string? tags, int requestingUserId);

    // Browse and search (always access-filtered)
    Task<List<DocumentListItem>> GetDocumentsAsync(DocumentQuery query, int requestingUserId);
    Task<List<DocumentListItem>> GetProjectDocumentsAsync(int projectId, int requestingUserId);
    Task<List<DocumentListItem>> GetTaskDocumentsAsync(int taskId, int requestingUserId);
    Task<List<DocumentListItem>> GetRecentDocumentsAsync(int requestingUserId, int count = 5);
    Task<int> GetDocumentCountAsync(int requestingUserId);          // documents the user uploaded
    Task<DocumentListItem?> GetDocumentAsync(int documentId, int requestingUserId);

    // Content access (also records Download / Preview activity)
    Task<DocumentContent?> OpenForDownloadAsync(int documentId, int requestingUserId);
    Task<DocumentContent?> OpenForPreviewAsync(int documentId, int requestingUserId);   // null if type not previewable

    // Sharing
    Task<DocumentOperationResult> ShareWithUserAsync(int documentId, int targetUserId, int requestingUserId);
    Task<DocumentOperationResult> ShareWithDepartmentAsync(int documentId, string department, int requestingUserId);
    Task<DocumentOperationResult> RevokeShareAsync(int documentShareId, int requestingUserId);
    Task<List<DocumentShareInfo>> GetSharesAsync(int documentId, int requestingUserId);   // owner only

    // Task link
    Task<DocumentOperationResult> AttachToTaskAsync(int documentId, int taskId, int requestingUserId);
    Task<DocumentOperationResult> DetachFromTaskAsync(int documentId, int requestingUserId);
}

public record DocumentContent(Stream Content, string FileName, string ContentType, long Length);
```

Behavior contract:

| Method | Success | Failure results |
|---|---|---|
| `UploadAsync` | Document created, file stored, `Upload` activity logged, project members notified | `Error` = unsupported type / too large / empty / signature mismatch / malware found / scan unavailable ("try again later") / not allowed for project / invalid title or category |
| `ReplaceFileAsync` | New file stored, record updated, old file removed, `ReplaceFile` logged | Same validations as upload; only the uploader; original kept on any failure |
| `DeleteAsync` | Rows and file removed; `Delete` logged | Not found or not allowed |
| `UpdateMetadataAsync` | Fields saved, `UpdatedDate` set, `EditMetadata` logged | Not found or not allowed; invalid title/category/tags |
| `GetDocumentsAsync` | Items filtered by scope/search/filters and by the user's view access; sorted by `SortBy` (`Title`, `UploadDate`, `Category`, `FileSize`) | Empty list |
| `GetProjectDocumentsAsync` | Documents of the project if the user is manager/member/admin | Empty list |
| `OpenForDownloadAsync` / `OpenForPreviewAsync` | Stream plus metadata; activity logged | `null` when not found or no view access (indistinguishable) |
| `ShareWith*Async` | Share row, `Share` activity, notification(s) | Not the uploader; unknown user; duplicate share; self-share |
| `RevokeShareAsync` | Share removed, `RevokeShare` logged | Not the uploader or not found |
| `AttachToTaskAsync` | `TaskId` set and `ProjectId` aligned to the task's project | Not the uploader, or user cannot view the task |

Test obligations (per `DocumentService` method): authorized path, each denied role, nonexistent id, and no side effects (file or row) on failure.

## IDocumentReportService (Administrator only)

```csharp
public interface IDocumentReportService
{
    Task<List<UploadTypeReportRow>> GetUploadsByTypeAsync(DateTime? from, DateTime? to, int requestingUserId);
    Task<List<TopUploaderReportRow>> GetTopUploadersAsync(DateTime? from, DateTime? to, int top, int requestingUserId);
    Task<List<AccessPatternReportRow>> GetAccessPatternsAsync(DateTime? from, DateTime? to, int requestingUserId);

```

Non-Administrators receive an empty list (same convention as other services).
